Project guide
How to use the workspace and understand its results.


Your first review
Run the example, then open a finding to read the explanation and suggested change. Select its line number to jump into the editor. Try fixing it and running the review again.
How the browser engine works
A nearest-neighbor model compares each line with labeled examples of Python and JavaScript. A few explicit checks cover recognizable patterns such as a bare Python exception handler. Each finding identifies its source. Review the surrounding code before applying a change.
Whole-file AI review
The downloadable Python server can send a file to an Ollama model running on your computer. Start the server and Ollama, then choose the Ollama engine in the local workspace. See the README in the source project for setup.
What gets saved
Completed reviews include a copy of your code in browser storage. Open Review history to revisit or delete an entry. Download a Markdown report to keep a separate copy.
